# Sheshumadhava Pittala — Portfolio starter

A dark, futuristic, responsive React + Vite + Tailwind CSS portfolio.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
cd shesh-portfolio
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production
```bash
npm run build
npm run preview
```

## Before publishing
1. Verify all project descriptions and technology stacks.
2. Replace GitHub profile links on project cards with each exact repository URL when ready.
3. Add a current PDF resume to `public/resume.pdf` and add a resume button if desired.
4. Confirm email and LinkedIn URLs.
5. Do not claim a project is complete if it is still a prototype or in progress.

## Stack
- React
- Vite
- Tailwind CSS v4 (Vite plugin)
- lucide-react icons

Tailwind's official Vite installation guide: https://tailwindcss.com/docs/installation/using-vite
